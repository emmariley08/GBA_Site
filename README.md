# Community Themed GBA Game
A custom-built Game Boy Advance game inspired by the legendary Community paintball episodes. Designed from the ground up for the GBA hardware, this project blends retro handheld limitations with fast-paced gameplay, sound integration, and themed mechanics.

## Overview
This game puts players in the middle of a frantic battle inspired by Community’s iconic paintball wars. The game was developed specifically for the Game Boy Advance and uses Mode 4 rendering to handle sprite and background graphics efficiently.
  
  * Technical mastery of low-level GBA graphics.
  * Integration of audio systems for background music and sound effects.
  * A retro-style design with nods to both handheld classics and modern storytelling.

## Installation
Option 1:
  1. Click the link in pages to play on an online emulator

Option 2:
  1. Download the .gba ROM file from the project release.
  2. Open with any emulator such as VisualBoyAdvance or mGBA.
  3. Play!

Option 3:
  1. Flash the .gba file to a GBA flashcart (e.g., EZ-Flash Omega).
  2. Insert into your GBA.
  3. Enjoy the retro experience.

## Controls
  * D-Pad → Move your character.
  * A Button → Shoot paintball.
  * B Button → Dodge/roll.
  * Start → Pause menu.
  * Select → Restart match.
